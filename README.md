# 내 꽃 정하기 · maydly

촬영에 들 꽃을 고르는 도구. 마음(또는 색) → 꽃 → 형태 → 색 → 양 → 드는 법 → 준비 순으로
고르면 꽃집에 그대로 가져갈 수 있는 정리표가 나온다.

- 공개 주소: https://maydly.github.io/flower/
- 검색 노출은 막아 두었다(`noindex`). 링크를 아는 사람만 본다.

## 파일

| | |
|---|---|
| `index.html` | 도구 본체 |
| `data.js` | 꽃 70종 데이터 (자동 생성물 — 직접 고치지 말 것) |
| `img/` | 꽃 사진 70장 |

## 고치는 법

이 저장소를 직접 고치지 않는다. 원본은 Drive 작업폴더에 있다.

```
maydly-project/01_진행중/기능-002_촬영꽃소품_준비안내와대행옵션/1_꽃소품안내페이지/
├── 1-2_데모/     ← 여기서 고친다
│   ├── 꽃데이터_생성.py   꽃 정보 (종류·시기·값대·형태)
│   ├── 꽃말데이터.py      꽃말과 뜻 설명
│   └── 꽃이미지_받기.py   사진 수집
└── 1-4_배포/     ← 고친 뒤 여기로 복사해 올린다
```

`python3 꽃데이터_생성.py` 를 돌리면 `꽃데이터.js` 가 다시 만들어진다.

## 사진 저작권

꽃 사진은 위키미디어 공용에서 가져왔고, 페이지 하단에 저작자·라이선스를 밝혀 두었다.
전부 CC 또는 퍼블릭 도메인이다. **직접 촬영한 사진으로 교체하면 해당 항목을 출처 목록에서 뺀다.**

## 아직 확인 전인 것

수급 시기 · 구매처 등급 · 값대 · 조화/드라이 가능 여부는 일반 기준에 따른 초안이다.
화면에도 "확인이 필요하다"고 적어 두었고, 꽃집에 전화로 물어볼 문장을 함께 제공한다.
